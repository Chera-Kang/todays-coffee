# 오늘의커피 (Today's Coffee)

> **커피 큐레이션 및 영양성분 탐색 웹 서비스**  
> 국내 대표 8대 커피 프랜차이즈(스타벅스, 메가커피, 컴포즈커피, 폴바셋, 투썸플레이스, 이디야커피, 빽다방, 할리스)의 커피부터 논커피까지, 음료 영양성분과 원두 특징을 감각적인 에디토리얼 UI로 탐색하고, 오늘 나의 컨디션에 맞는 커피 큐레이션 및 일일 카페인 섭취량을 기록하는 서비스입니다.

🌐 **웹 서비스 바로가기**: [https://todays-coffee.pages.dev/](https://todays-coffee.pages.dev/)

---

## ☕ 1. 기술 스택 (Tech Stack)
- **Frontend Core**: React 19 (Vite 8)
- **Styling**: Tailwind CSS v4, Vanilla CSS
- **Typography & Design**: Pretendard Variable 웹폰트, 29CM/화해 스타일 Warm Cafe Minimalism (`#FAF8F5`, `#231915`)
- **Illustrations & Icons**: 순수 Inline SVG 동적 음료 썸네일 (`DrinkThumbnail`), `lucide-react` 라인 아이콘
- **Architecture**: No-Backend Architecture (8대 브랜드 45종 JSON SSOT + LocalStorage CRUD 영속화 + HTML5 History API)

---

## 🎯 2. 주요 기능 및 특징

### ① 히어로 & 맞춤 추천 큐레이션 (Tab 1)
- **상황별 큐레이션**: `야근·집중 부스터`(150mg↑), `식단 관리·제로슈거`(5g↓ & 50kcal↓), `오후 3시 이후 디카페인`(30mg↓), `운동 전 아메리카노`(150mg↑ & 30kcal↓)
- **결정 장애를 위한 '오늘 뭐 마시지?'**: 8대 브랜드 메뉴 중 1종을 즉각 무작위 셔플 추천
- 6대 카테고리 필터, 8대 브랜드 칩, 실시간 검색어 완벽 교집합 연동

### ② 2-Tier 음료 탐색 & 정렬 (Tab 2)
- **독립 컴포넌트 아키텍처**: 필터 패널, 검색, 정렬 팝오버, 벤토 그리드를 `DrinksExploreView`로 캡슐화
- **성분 게이지 시각화**: 일일 카페인(400mg) 및 당류(50g) 미니 프로그레스 바
- **정렬 옵션**: 카페인/칼로리/당류 기준 높은순·낮은순 6종 정렬 (외부 클릭 시 닫힘)

### ③ 커피 상세 모달 & 타 브랜드 메뉴 비교
- **영양성분 테이블**: 목록 UI와 통일된 직관적 배치 (카페인 ➔ 당류 ➔ 칼로리 ➔ 단백질)
- **타 브랜드 메뉴 비교**: 동일 카테고리 타 브랜드 메뉴 2종 추천 및 1:1 즉시 전환 (스크롤 최상단 리셋)
- **모바일 네이티브 뒤로가기**: 안드로이드/브라우저 뒤로가기 시 페이지 이탈 없이 열려 있던 모달만 닫힘

### ④ 일일 카페인 트래커 & 숙면 가이드 (CRUD)
- **한 줄 테이스팅 메모**: 최대 30자, 공백 불가, 특수문자 제한 인라인 유효성 검증
- **숙면 안심 컷오프 가이드**: 누적 섭취량과 체내 카페인 반감기(5~6h)를 계산한 안심 시간대 안내
- **자정(00:00) 자동 초기화**: 자정 경과 시 `localStorage` 데일리 자동 리셋 및 화면 활성화 시 실시간 감지
- **권장량 초과 경고**: 400mg 초과 시 붉은 테두리 및 삼각 경고 아이콘 활성화

### ⑤ 원두 가이드 & 브랜드 비교 (Tab 3 & 4)
- **원두 가이드**: 산미/바디감/로스팅 5단계 시각화 및 테이스팅 태그 필터
- **브랜드 비교**: 8대 브랜드 아메리카노 기준 용량, 가격, 100ml당 단가(가성비 바) 인포그래픽 비교

### ⑥ 라우팅 & 예외 처리 (UX 완성도)
- **메뉴별 고유 URL Page화**: `#drink-{id}`, `#tab={tab}`, `#tracker` 해시 라우팅으로 공유 지원
- **404 Blank 페이지**: 잘못된 주소 접근 시 에디토리얼 404 안내 및 10초 후 첫 페이지 자동 복귀

## 📊 3. 데이터 구조 (Data Architecture)

별도의 백엔드 서버 없이 정규화된 JSON 데이터셋을 단일 진실 공급원(SSOT)으로 사용합니다:
- `src/data/menus.json`: 8대 브랜드 45종 음료 영양성분 및 BVA(경계값) 테스트 데이터
- `src/data/beans.json`: 브랜드별 대표 원두 12종의 로스팅 강도, 산미, 바디감 및 플레이버 태그
- `src/data/brands.json`: 8대 브랜드 시그니처 컬러, 기준 용량, 가격 데이터
